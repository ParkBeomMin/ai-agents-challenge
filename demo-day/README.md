## 왜용

**아이의 질문을 “학습”으로 바꾸는 대화형 학습 도우미**입니다.  
아이의 순수한 질문을 그대로 두지 않고, 질문의 의도를 파악해 학습 주제로 정리한 뒤 **연령/수준에 맞는 설명**을 제공합니다. 필요하면 **간단한 실험**으로 확장하고, 마지막에는 **학습 기록**과 **다음 질문 추천**까지 이어지도록 설계했습니다.

### 한 줄 목표

- 아이의 질문을 출발점으로, 이해 → 확인 → 보완 → 확장 → 기록까지 자연스럽게 이어지게 한다

### 핵심 기능

- **질문 해석 & 주제화**: 질문의 의도를 분석하고 학습 가능한 주제로 변환
- **눈높이 설명**: 과학적 해석을 바탕으로 연령/수준에 맞게 설명 생성
- **이해도 확인**: 이해도 확인 질문을 던지고 아이의 답변을 평가
- **맞춤 분기**: 부족하면 재설명, 가능하면 퀴즈/실험(활동)로 확장
- **학습 기록 & 추천**: 학습 내용을 저장하고 관련 질문을 생성/추천

### 처리 흐름(그래프)

```mermaid
flowchart TD
  A[질문 입력] --> B[질문 의도 분석]
  B --> C[학습 주제 변환]
  C --> D[연령/수준 판단]
  D --> E[눈높이 설명 생성]
  E --> F[이해도 확인 질문]
  F --> G[아이 답변 평가]

  G --> H{다음 액션}
  H -->|이해가 부족함| R[재설명]
  H -->|개념을 점검하고 싶음| Q[퀴즈 생성]
  H -->|직접 해보면 좋음| X[실험(활동) 추천]

  R --> S[학습 기록 저장]
  Q --> S
  X --> S
  S --> T[관련 질문 추천]
```
